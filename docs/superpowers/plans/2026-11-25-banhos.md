# Registo de Banhos Implementation Plan

**Goal:** Registar e consultar os banhos da Sofia, como as fraldas.
**Architecture:** Mesmo molde das fraldas. O separador vive em `src/components/BanhosTab.jsx` (Leite.jsx já é grande).
**Tech Stack:** React 19, Express, PostgreSQL, `node --test`.
**Spec:** docs/superpowers/specs/2026-11-25-banhos-design.md

## Global Constraints
- Guardar só `id, data (yyyy-MM-dd), hora (HH:mm)`. Sem dependências novas.
- Vermelho a partir de 48 h; texto em dias a partir de 24 h.
- Ecrãs grandes: cartões 2 x 2; telemóvel: um por baixo do outro.

## Review Focus
- Hora registada "no futuro" no próprio dia (conta como ontem, como nos outros registos).
- Sem banhos registados (cartão e separador com estado vazio).
- Dados antigos intactos: só `CREATE TABLE IF NOT EXISTS`.
- Quatro separadores a 320 px sem sair do ecrã.
- Pedido de voz sem corpo (`GET /api/banhos/registar`) usa data e hora de Lisboa.

## Tasks
1. `tempoDesdeBanho(data, hora, agora) -> {text, isUrgent} | null` em `src/services/banhos.js`; teste `tests/banhos.test.mjs`.
2. Servidor: tabela `banhos`, `GET/POST /api/banhos`, `GET /api/banhos/registar`, `/api/webhook/banhos`,
   `DELETE /api/banhos/:id`, `ultimo_banho` em `/api/ha/status`. Teste com `pg` simulado.
3. Cliente: `api.getBanhos/saveBanho/deleteBanho` (chave `sofia_banhos`); `BanhosTab({ data })`; separador "Banhos".
4. Início: cartão "Último Banho", grelha 2 x 2, estilo Natal. Verificação no browser.
